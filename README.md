## 🎯 Sobre o Projeto

O **Guia do Orçamento Familiar** é um product landing page (PLP) profissional e responsivo que apresenta um método prático e comprovado para organizar as finanças pessoais de forma simples e eficaz.

A página foi otimizada para **conversão e SEO**, com estrutura HTML/CSS limpa, dados estruturados (Schema.org) e design moderno que destaca os benefícios do produto.

---

## ✨ Características Principais

- ✅ **Design responsivo** - Funciona perfeitamente em desktop, tablet e mobile
- ✅ **Otimizado para SEO** - Meta tags, Open Graph, Twitter Card e Schema.org
- ✅ **Performance** - CSS separado, sem JavaScript desnecessário
- ✅ **Conversão focada** - CTA estratégicos com copy persuasivo
- ✅ **Prova social** - Seção com depoimentos de clientes reais
- ✅ **FAQ completo** - Respostas às objeções mais comuns

#### Personalizações

Para adaptar o projeto:

1. **Meta tags SEO** - Edite as tags em `index.html` linhas 6-63
2. **Conteúdo** - Modifique os textos diretamente no HTML
3. **Cores** - Altere as variáveis CSS em `css/styles.css` (linhas 1-14)
4. **Imagem OG** - Substitua `og-image.jpg` por sua imagem (1200x630px)
